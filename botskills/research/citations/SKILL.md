# citations

## Workflow

1. Capture the URL and access date at the moment of reading.
2. Quote the sentence that supports the claim, not the page title.
3. Record author/publisher and publication date; mark undated sources.
4. Prefer stable links (DOI, permalink) over search results.
5. Format consistently in one style for the whole document.
6. Verify every link resolves before delivery.

## Quality checks

- Every citation has a working link and a quote.
- No citation is used for a claim it does not support.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
