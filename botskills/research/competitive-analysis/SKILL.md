# competitive-analysis

## Workflow

1. Define the comparison dimensions before researching (pricing, features, audience, integrations).
2. Use the vendor's public pricing and docs as primary sources; note the date.
3. Build a matrix: dimension × competitor, with a source per cell.
4. Mark unknowns explicitly instead of guessing.
5. Summarise where the product wins, ties and loses.
6. Refresh prices because they change; state the retrieval date.

## Quality checks

- Every price cell has a source and date.
- Unknown cells are marked, not filled with assumptions.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
