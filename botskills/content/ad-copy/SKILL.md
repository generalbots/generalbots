# ad-copy

## Workflow

1. Define audience, pain and promised outcome before writing.
2. Three angles: pain, outcome, contrarian. One hook each.
3. Primary text ≤125 chars; headline ≤40; description ≤30 where the platform requires.
4. Every variant differs in one variable so the test is readable.
5. No claims the landing page cannot substantiate.
6. Name the metric each variant is meant to move.

## Quality checks

- Variants are meaningfully different, not synonyms.
- No policy-violating claims (guaranteed results, before/after).

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
