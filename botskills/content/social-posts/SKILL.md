# social-posts

## Workflow

1. Pick the platform's native format: hook line, body, CTA, hashtags.
2. LinkedIn: short lines, a concrete story, 3-5 hashtags at the end.
3. Instagram: caption with line breaks, ≤5 relevant hashtags, alt text for the image.
4. X: one idea ≤280 chars; thread only when the idea needs steps.
5. No engagement bait; no hashtags inside sentences.
6. Provide a variant for the platform the user did not ask about only if useful.

## Quality checks

- Length fits the platform limit.
- Hashtags are relevant and not duplicated across variants.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
