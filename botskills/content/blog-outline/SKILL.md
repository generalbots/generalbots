# blog-outline

## Workflow

1. List the questions a reader needs answered, ordered by decision stage.
2. Map each to an H2 with the answer in one sentence (the 'so what').
3. Add evidence slots: stat, example, quote, source to find.
4. Define the takeaway and the CTA at the end.
5. Flag sections that need original data versus synthesis.
6. Estimate length per section from the depth needed.

## Quality checks

- Every H2 answers a real question, not a keyword variant.
- The outline names what evidence each claim needs.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
