# video-script

## Workflow

1. Hook in the first 3 seconds: tension or promise, no logo intro.
2. Beats: setup → problem → demo → payoff, one per 10-15 seconds.
3. Write spoken lines and separate visual/b-roll cues.
4. On-screen text supports, never repeats the narration.
5. CTA in the last 3 seconds; keep it single.
6. Read aloud at 150-160 wpm to check length.

## Quality checks

- The script's runtime matches the target duration.
- Every beat advances the story; nothing is filler.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
