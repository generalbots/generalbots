# seo-on-page

## Workflow

1. Match the search intent (informational, commercial, transactional) with the page type.
2. Title ≤60 chars with the primary phrase near the front; description ≤155 chars.
3. One H1; H2s cover the questions the intent implies.
4. Internal links with descriptive anchors to related pages.
5. Structured data (Article/Product/FAQ) matching the visible content.
6. Check cannibalisation: one page per intent.

## Quality checks

- Title, H1 and description are consistent with each other.
- No structured data that the page does not show.

## Output

Write the artefact to `output/` and report its path plus one line on what it contains. Never claim a result you did not open and check.
