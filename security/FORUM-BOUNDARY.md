# Forum boundary

The Go-based community forum is for discussion. `/security/` is the single
authoritative source for advisories. A forum thread can never create, amend,
retract or date an advisory, and no advisory is published first on the forum.

Each security category on the forum links to `/security/` and to
`/.well-known/security.txt`. Moderators lock or mark threads that contradict a
published advisory and point readers at the canonical bulletin; they never
edit the advisory itself. The bulletin explains this boundary to readers so a
thread is not mistaken for an official statement.
