Perguntas frequentes

Este boletim substitui o fórum da comunidade?

Sim, para avisos oficiais. O fórum serve apenas para discussão; a versão publicada aqui e no feed CSAF é a única fonte autoritativa.

Como sei qual versão corrigiu um problema?

Cada aviso lista o intervalo exato de versões afetadas e a primeira versão corrigida. Confirme sempre o número da versão antes de atualizar.
