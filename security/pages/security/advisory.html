GBSA-2026-0001 — Injeção de HTML na edição de documentos e planilhas

PT-BR Versão autoritativa: português (Brasil). Em caso de divergência entre traduções, esta versão prevalece.

Resumo

Um usuário autenticado pode injetar HTML em títulos de documentos e planilhas, afetando outros participantes da sessão de colaboração. A versão 6.8.12 corrige o problema.

Impacto e versões afetadas

Confidencialidade e integridade: scripts arbitrários podem ser executados no navegador de outros usuários. Versões 6.8.0 a 6.8.11 são afetadas; outras plataformas não são.

Gravidade

Crítica — CVSS 4.0, pontuação base 9.3 (AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N).

Correção

Atualize para a versão 6.8.12 ou superior. Não existe solução alternativa validada; a atualização é a única medida recomendada.

Perguntas sobre este aviso

Este problema está sendo explorado?

Não há evidência de exploração ativa no momento da publicação. Novas evidências atualizam o aviso e exigem uma nova revisão.

Como verifico a versão instalada?

Consulte a tela de configurações do servidor ou execute o comando de versão na interface de linha de comando antes de aplicar a atualização.
