# Upload-validation gate allowlist (#2132) — SHRINK-ONLY.
#
# Every entry is a handler the scanner sees as an upload surface (it reads a
# whole body: `body: String`, `body: Bytes` or `body: axum::body::Body`) but
# which does not store a file. Removing the entry is required as soon as the
# handler validates or disappears — the gate fails on a stale entry.
#
# Format:  <repo-relative path>::<function> | <why it is not a file upload>
#
# Adding a line here is a security decision: only bodies that are parsed into
# rows/messages (never written as a file, never served back) belong here.

botserver/crates/botconsent/src/api.rs::resolve_consent | JSON consent decision parsed into a struct
