# General Bots Documentation

A short guide to what ships today. Reference tables on this site are generated
from the source code — apps come from the suite registry, endpoints from the
mounted routes, keywords from the BASIC compiler and schemas from `botschema`.

## Start here

- [Getting Started](./01-getting-started/README.md) — install, configure, first bot.
- [Suite Apps](./07-user-interface/apps/README.md) — the app catalog and its status.
- [Build a bot](./04-basic-scripting/README.md) — BASIC, tools and knowledge.
- [Channels](./06-channels/README.md) — connectors and webhooks.
- [AI OS](./13-ai-os/README.md) — skills, retrieval and engines.
- [Reference](./08-rest-api-tools/generated/README.md) — generated API, schema and keyword tables.
- [Operate](./10-configuration-deployment/README.md) — deployment and production.

## What is current

The product version is **7.1.2** (`Cargo.toml`). Plans and open work live in
[GitHub issues](https://github.com/generalbots/generalbots/issues), not in this
guide. Pages that describe unreleased behaviour are marked with their maturity.
