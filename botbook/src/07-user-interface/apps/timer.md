# Timer 🟡 PREVIEW

> **Preview application.** Usable today, not yet part of the supported surface.

Timer is a countdown and focus timer that lives in the suite, so a session timer does not have to live on another device.

## What it does

| Capability | Detail |
|---|---|
| **Countdown** | Set a duration and run it down |
| **Focus sessions** | Built for work intervals rather than one-off alarms |
| **Desktop presence** | Runs as a window in the desktop shell, alongside the work it times |

## Choosing between the time apps

The suite has three time-related surfaces, and they are not interchangeable:

| App | Purpose |
|---|---|
| **Timer** | A countdown for the next N minutes |
| [Time Clock](./timeclock.md) | Attendance and worked hours, with overtime records |
| [Clock widget](clock-widget.md) | Always-on current time on the desktop |

Use Timer for attention, Time Clock for the record, and the Clock widget for orientation.

## Opening it

Timer is a **preview** application. Turn on the **Preview** switch in the left sidebar, then open **Timer** from the app menu.
