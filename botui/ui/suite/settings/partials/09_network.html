Network

Control whether this installation participates in the peer network

P2P Network

Offline

Offline — every connection stays on 127.0.0.1. Shared links work on your local network only.
P2P — enables future features such as free shared-link relaying and peer discovery. No data leaves this machine until you explicitly share something.

This preference is saved locally and takes effect after the app restarts. The relay endpoint is managed automatically (relay.generalbots.org); no manual configuration is required.
