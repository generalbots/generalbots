Keyboard shortcuts

Press Shift + ? anywhere in the suite to open this list.

General

Ctrl + KCommand palette
Ctrl + ,Privacy settings
/Focus chat input
Shift + ?Show this help
EscapeClose modal / clear selection
PageUp / PageDownScroll chat history
TabNavigate between elements
EnterActivate focused element

Drive

DeleteDelete selected files (Drive)
Ctrl + ASelect all files (Drive)
Ctrl + C / X / VCopy / Cut / Paste files
BackspaceNavigate up in Drive
F2Rename selected file

Shortcuts are ignored while you are typing in a field, so they never interrupt a message or a form.
